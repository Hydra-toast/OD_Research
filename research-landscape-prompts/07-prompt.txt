Research Landscape — 07/14 로컬 저장·내보내기와 P0 완료 검증

[이전 단계 이어받기]
먼저 AGENTS.md와 docs/PRODUCT_CONTRACT.md, docs/PROGRESS.md, docs/DECISIONS.md, docs/TEST_MATRIX.md를 읽어라. 계약 파일이 없다면 1번이 아직 적용되지 않은 것이므로 전제를 추측하지 말고 필요한 1단계 기록부터 복원하라. 기존 사용자 변경과 작동 기능을 보존하라.
지정된 이번 단계만 구현·검증하고 다음 번호를 자동 실행하지 마라. 선행 결손은 이번 작업에 필요한 범위에서 먼저 수정하라. 키·계정이 없으면 독립 구현과 고정 응답 테스트를 진행하되 실제 연동은 미검증으로 남겨라. 보안이나 데이터 무결성 전제는 우회하지 마라.

7/14단계: P0를 완성하라. 이 검증이 끝나기 전에는 외부 서비스 연결로 넘어가지 않는다.

[저장]
IndexedDB ProjectRepository로 저장한 조사 목록, 열기, 이름 변경, 자동 저장, 삭제를 구현한다.
원래 입력·현재 범위·연구실 정보·선택·메모·수정·Claim·예시 자료·분석 버전을 저장한다. 스키마 버전과 마이그레이션을 둔다.
‘이 브라우저에 저장됨’을 표시하고 클라우드/계정 동기화처럼 표현하지 않는다. 저장 실패와 저장 중 상태를 구분한다.
깨진 저장 데이터는 조용히 지우지 말고 복구 안내나 원본 내보내기를 제공한다. 삭제에는 대상 이름과 삭제 범위를 알린다.

[내보내기]
1) 한 페이지 요약 내용: 질문, 선택한 방향 2~3개(실제 선택이 적으면 그대로), 핵심 근거, 랩 연결, 미확인, 다음 논문/행동.
2) 외부 PPT 도구용 가이드: 슬라이드 제목, 핵심 문장, 필요한 그림·표·자료, 논문과 위치, 설명의 한계.
복사와 UTF-8 Markdown 다운로드를 구현한다. 브라우저 클립보드 실패 시 선택 가능한 텍스트를 제공한다.
제목·URL·줄바꿈을 안전하게 처리한다. 출처·자료 범위·미확인·예시 표시는 파일에도 남긴다. 실제 PPT 생성은 하지 않는다.
한 페이지 인쇄 레이아웃은 13단계에서 추가한다.

[P0 검증]
대표 흐름: 예시 선택 → 범위 조정 → 논문/방향 선택 → Claim 수정·근거 확인 → 저장 → 새로고침 후 복원 → Markdown 내보내기 → 프로젝트 삭제.
추가: 0건, 초록 전용 논문에 위치 미생성, 지연 응답 역전, 저장 실패, 모드 분리.
checkJs, 단위 테스트, Playwright를 실행한다. 1280px와 375px에서 주요 화면 캡처. 실제 브라우저 200% 확대는 가능한 도구로 별도 확인한다. deviceScaleFactor=2나 CSS 확대를 실제 브라우저 확대 검사라고 부르지 않는다. 지원되지 않으면 미검증으로 기록하고 축소 viewport 보조 검사를 구분한다.
일반 페이지 가로 넘침, 키보드 포커스, reduced-motion, 결과/다운로드의 예시 라벨을 확인한다.

[완료 기준]
외부 키 없이 핵심 흐름이 동작해야 한다. 오류를 수정하고 P0 통과/실패/미검증 표와 캡처 경로를 docs/PROGRESS.md에 남긴다. ‘사이트 전체 개발 완료’가 아니라 ‘P0 예시 모드 완료’로 보고한다.

[단계 종료]
이번 변경, 검사 결과, 미완료·외부 미검증, 필요한 설정, 다음 번호를 docs/PROGRESS.md에 갱신하고 결정이 달라졌으면 docs/DECISIONS.md에 근거를 남겨라. 수행하지 않은 검사·연동·저장을 완료라고 보고하지 마라. 필수 조건이 실패하면 다음 입력 전에 해결할 항목을 밝혀라. 최종 답변은 구현 결과·확인 결과·남은 항목·다음 번호만 간결하게 작성하라.
