# PC PDF 자동 가져오기

1. 프로젝트 폴더에서 기존 서버를 종료하고 node scripts/pc-inbox.js 를 실행합니다.
2. ondot.my 조사 화면의 PC PDF 자동 가져오기에 터미널의 연결 코드를 입력합니다.
3. 브라우저의 로컬 네트워크 접근을 허용합니다.
4. 자동 가져오기를 켜고 현재 조사에 연결합니다. 표시된 수신 폴더에 PDF를 저장합니다.

서버는 127.0.0.1:5173에서만 열립니다. 연결 코드는 실행마다 바뀌며 탭 세션에만 저장됩니다. https://www.ondot.my만 연결을 허용합니다. 공개 사이트 프런트엔드를 새 코드로 배포해야 연결 UI가 나타납니다. 브라우저별 로컬 접근 제한으로 연결이 거절되면 localhost에서 이용할 수 있습니다.
