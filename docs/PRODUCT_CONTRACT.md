# Research Landscape 제품 계약

## 최신 기준

2026-10-21 PRD v2.0이 현재 제품·개발 기준이다. 상세 요구사항은 [.cursor/Research-Landscape-PRD.md](../.cursor/Research-Landscape-PRD.md)를 따른다. 기존 14개 단계와 변경 프롬프트는 참고 자료이며 충돌하면 최신 PRD가 우선한다. 이 계약 변경은 기능 구현 완료를 뜻하지 않는다.

## 목적과 사용자

교수님 말씀과 개인 연구 메모에서 조사 질문을 준비하고, 여러 검색식으로 논문을 모아 읽을 순서·비교·근거·랩미팅 자료를 정리하는 개인 연구 도구다. 공개 판매·다중 사용자 서비스로 개발하지 않는다.

전공을 제한하지 않는다. 기존 EUV PR·ALD·HBM 가상 예시를 유지하되 고분자·소재·화학 등에도 같은 조사 구조를 적용한다. 특정 분야의 공정 항목을 강제하지 않으며 자료가 부족하면 미확인으로 남긴다.

## 유지하는 뼈대

- 기존 HTML/CSS/JavaScript ES modules와 Node.js·Express, 같은 출처의 UI/API를 유지한다.
- 탐색과 랩미팅 준비 두 화면, 연구실·검색식·근거 보조 패널, 저장한 조사를 유지한다.
- 기존 선택·메모·비교·Claim·근거·버전·Markdown 내보내기와 디자인 토큰을 재사용한다.
- 사용자 변경·저장 데이터·개인 .env를 임의 삭제하거나 reset하지 않는다. 자동 커밋하지 않는다.
- research-landscape-prompts/ 원본은 수정하지 않는다.

## AI와 외부 작업

- 사이트는 OpenAI·Gemini 등 모델 API를 호출하지 않는다. 무료 API도 기본 의존성에 넣지 않는다. 기존 키가 있어도 개인 핵심 흐름에서 자동 호출하지 않는다.
- 일반 코드가 목적별 프롬프트와 입력 자료를 미리 작성한다. 사용자가 확인·편집·복사해 외부 AI에서 실행하고 결과를 가져온다.
- 지원 목적은 상담·검색식 생성, 검색어 보완, 논문 관련성 검토·독해, 방향·연구실 연결, 비교, 랩미팅 초안, 피드백 반영이다. 후속 미구현 목적은 완료로 표시하지 않는다.
- 첫 상담에 잠정 주제·영문 핵심 키워드·검색식 5~8개를 요청한다. 확인 질문·가정을 남기되 주제 선택 대기로 검색식을 비우지 않는다. 해석할 대상이 전혀 없으면 이유를 표시한다.
- 빈 필수 필드·형식 오류는 원문과 이전 결과를 보존한 보완 요청으로 복구한다. 외부 AI 결과의 스키마·ID·자료 버전을 검증하고 사용자 확인 후 적용한다.
- 외부 AI 로그인·세션·쿠키·브라우저 자동조작으로 모델 API를 대신하지 않는다. 직접 입력·수동 정리는 항상 가능해야 한다.

## 검색·정렬

- OpenAlex 주 검색, Crossref 결측 보완·장애 대체를 유지한다. Semantic Scholar 의존을 다시 넣지 않는다.
- 검색식 최대 8개, 기본 최대 2개 동시 작업이며 실제 공급자 제한에 맞춰 더 낮출 수 있다. 수집·실패·0건·대체 출처를 구분한다.
- DOI·공급자 ID 중복 제거, 발견 검색식·필드 출처 보존, rule-v1 기본 관련성 정렬을 유지한다. 의미 분석·논문 품질 점수로 표현하지 않는다.
- 검색 API에는 확인한 검색식·필터만 전달하고 교수님 원문·연구실 메모를 통째로 보내지 않는다. 키·이메일은 서버에서 관리한다.
- 공급자 무료 범위·가입·키·원문 접근 조건은 실제 연결 시 확인한다. 무제한 무료라고 표현하지 않는다.

## 저장과 개인 서버

- IndexedDB와 전체 백업·복원을 기본으로 한다. 계정·Supabase·클라우드 배포는 필수 조건이 아니다.
- 기본 서버는 개인 PC의 127.0.0.1에서 동작한다. 원격 공개는 별도 요청 전 자동으로 열지 않는다.
- 로컬 저장을 계정 보안·클라우드 동기화로 표현하지 않는다. 탭 충돌·저장 실패·손상·구버전·백업 충돌에서 원본을 보존한다.
- 원문은 전용 로컬 저장 영역을 목표로 한다. 기존 30일 자동 만료를 개인 원문에 강제하지 않고 임시 파일 정책과 사용자 삭제를 구분한다.
- 기존 클라우드·AI 코드와 기록은 임의 제거하지 않고 필수 경로와 분리한다.

## 방향·원문 확장

- 방향 카드·비교는 수동 작성 또는 외부 AI 결과 가져오기로 확장한다. 과거 8편 기준으로 개인 초기 메모를 차단하지 않는다. 연결 근거가 적으면 부족 상태를 표시한다.
- 공개 원문 후보·사용자 파일·개인 MCP 어댑터를 분리한다. 링크 발견·파일 확보·텍스트 추출·내용 확인은 서로 다른 상태다.
- Sci-Hub MCP는 이전 사용자 요청이 남은 개인용 확장 항목이며 현재 미구현이다. 구현 시 실제 도구 목록·호출·실패·다운로드·파일 검사를 수행해야 한다. 편집기 등록을 웹 도구 연동 완료로 보고하지 않는다.
- MCP·다운로드 실패가 검색·정리를 막지 않게 한다. 모델 API를 MCP 실행의 필수 경로로 두지 않는다.
- URL·DNS·리다이렉트·경로·형식·크기·시간을 검사하고 원문을 정적 공개 경로에 저장하지 않는다. 재배포 권한을 링크나 소프트웨어 라이선스로 확정하지 않는다.

## 신뢰성과 제외 범위

- 실제 논문·DOI·수치·원문 위치를 지어내지 않는다. 초록만 있으면 본문 페이지·그림 위치를 만들지 않는다.
- 형식 검증, 외부 AI 해석, 원문 확보, 사용자 확인을 같은 검증 상태로 합치지 않는다.
- 예시는 example: ID와 “가상 예시 · 실제 논문 아님” 표시를 유지한다. 사용자 제공 자료는 출처를 구분하고 실제 검색 실패를 예시로 바꾸지 않는다.
- 수치 비교는 단위·조건·근거를 보존한다. 수정 후 Claim의 사용자 확인을 해제한다.
- 가격·결제·구독·상품 FAQ·유료 잠금, 연구 공백·신규성·수주 보장, 적합도·준비도 점수, 일정 관리·자동 PPT 디자인은 범위 밖이다.

## 검증과 진행

checkJs·Vitest·Playwright 및 실제 자료 검증을 구분한다. 실행하지 않은 검사·외부 연결을 완료로 보고하지 않는다. 기존 기록은 과거 실행 시점의 증거다. 작업 후 docs/PROGRESS.md와 필요 시 TEST_MATRIX.md를 갱신한다. 최신 개발 우선순위와 인수 기준은 PRD v2.0의 10~11절을 따른다.
