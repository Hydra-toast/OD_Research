## 도구
- 타입: `npm run check` (tsc checkJs, 2단계에서 생성)
- 단위/통합: `npm test` (Vitest, 2단계에서 생성)
- UI: Playwright (4단계부터)
- 화면: 1280px, 375px, 실제 브라우저 200% 확대(CSS 확대·deviceScaleFactor=2는 대체 불가, 축소 viewport는 보조 검사로 구분)
