## 최종 구조와 이번 범위

전체 흐름은 검색 → 논문 선별·원문 확보 → 연구군·읽기 순서 정리 → 활용이다.
이번 단계는 **크기·작업 공간·논문 목록과 상세 분리·반응형**을 담당한다. 2단계는 기능 통합과 조작 감소, 3단계는 보존·회귀 검증을 담당한다.

확인할 진입점: parallel.html, parallel.css, styles.css, src/controller/render.js, src/views/explore.js, src/views/prepare.js. 이름에 의존하지 말고 현재 이벤트·상태·저장 경로를 확인한다.

## 구현 명세

1. 기본 화면 styles.css의 크기를 따른다. 최대 폭 1,240px, 본문 16px, 헤더 64px, 기본 버튼 최소 높이 40px. 카드·제목·입력창도 기본 스타일을 재사용한다. 패러렐의 1,380px 폭·압축 스타일·전역 중복 규칙을 정리한다. scale이나 글자 축소로 맞추지 않는다.
2. 검색 전에는 기존 입력 화면을 유지한다. 검색 후에는 큰 소개·입력 영역을 조사 주제·검색 수정·수집/선택/원문 수·저장 상태를 가진 작업 헤더로 교체한다. 검색 수정은 기존 값을 담은 편집 화면에서 수행하며, 열기·취소만으로 검색하거나 조사를 초기화하지 않는다.
3. 1,120px 초과에서는 왼쪽 약 42%에 목록, 오른쪽 약 58%에 현재 작업을 둔다. 오른쪽 작업은 논문 상세 / 연구군·읽기 순서 / 활용이며 기본은 연구군·읽기 순서다. 기존 동작하는 기능을 새 작업별 위치에 연결한다.
4. 작업 공간은 헤더를 제외한 남은 화면 높이를 사용한다. 목록과 현재 작업 본문은 각각 내부 스크롤하며, 같은 패널 안에 여러 세로 스크롤 컨테이너를 중첩하지 않는다. 30편 때문에 문서 전체가 길어지면 안 된다. 고정 버튼이 마지막 내용을 가리지 않게 한다.
5. 목록 행은 체크박스·[P#]·제목·저자/연도·원문 상태만 표시한다. 제목은 최대 두 줄, 전문은 상세에 표시한다. 원본 문자열은 보존한다. 새 페이지 번호나 더 펼치기 조작은 추가하지 않는다. 기존 수집 한도·추가 수집 기능은 유지한다.
6. 제목을 한 번 누르면 오른쪽에 해당 한 편의 전체 제목·서지·초록·DOI/출처·개별 원문 작업·메모를 표시한다. 체크박스는 선택만 바꾼다. 전체 논문의 메모 입력창을 만들지 않는다. 기존 메모 저장과 실패 안내를 재사용한다.
7. 오른쪽 상단에 원문 받기 / 정리 프롬프트 복사 / 결과 가져오기 접근점을 둔다. 목록을 끝까지 내리지 않고 기존 기능에 접근 가능해야 한다. 2단계에서 본문과 대상 선택을 통합한다.
8. 단계 앵커·탐색/준비 탭·좌우 전환·하단 준비 이동 버튼의 중복을 새 탐색 구조로 대체한다. 사용 중인 기능을 끊거나 가짜 버튼으로 대체하지 않는다. 2단계까지 남길 임시 접근점이 있으면 보고한다.
9. 1,120px 이하에서는 패널을 세로로 쌓지 않고 논문 목록 / 현재 작업 전환으로 제공한다. 논문 선택으로 상세에 이동하고 돌아오면 목록 위치를 복원한다. 본문 크기를 줄이지 않는다.
10. 저장한 조사·사용 안내는 작업 아래에 길게 쌓지 않고 기존 메뉴에서 별도 화면으로 접근하게 한다. 작업 전환·진행 상태 갱신 때 메모·입력·초점·스크롤을 보존할 구조를 마련한다. 비활성 작업의 대규모 DOM을 계속 생성하지 않는다.

## 이번 단계 완료 기준

- 0·1·30편 고정 자료로 목록·상세·작업 전환이 동작한다. 예시는 example: ID와 “가상 예시 · 실제 논문 아님”을 사용한다.
- 1440·1024·375px에서 목록 뒤에 긴 작업 화면이 이어지지 않고, 주요 작업에 목록 스크롤 없이 접근한다.
- 기본 화면과 폭·본문·기본 버튼 크기를 비교한다. 같은 저장본을 기본 화면에서도 열 수 있다.
- 키보드로 전환 가능하고 입력 ID가 중복되지 않는다. 실제 탭을 사용하면 선택 상태·방향키 이동·패널 연결도 구현한다.
- checkJs와 변경 관련 검사·기본 화면 대표 흐름을 실행하고 화면 캡처를 남긴다. 실행하지 못한 검사는 이유와 함께 미검증으로 기록한다.

docs/PROGRESS.md와 필요한 TEST_MATRIX.md·DECISIONS.md를 갱신한다. 최종 보고는 변경 파일·화면 캡처·검사 결과·남은 2단계 항목을 제시한다. **1단계를 마치면 멈춘다.** 프로젝트 접근이 없으면 구현했다고 말하지 말고 패치와 검증 절차를 제공한다.
