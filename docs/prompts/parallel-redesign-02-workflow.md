검색 → 논문 선별·원문 확보 → 연구군·읽기 순서 정리 → 활용 흐름을 유지하며, 원문·Gemini 정리를 하나의 작업으로 통합한다. 비교·발표·기타 AI 도움은 활용으로 모은다. 단순 접기·펼치기나 CSS로 숨기기만 하지 않는다.

## 구현 명세

### 검색과 대상 선택

- 패러렐의 기본 찾기는 기존 바로 찾기를 한 번에 실행한다. 찾기 → 바로 찾기라는 중간 클릭을 제거한다. 빈 입력·해석 한계·전송 정보 제한은 보존한다.
- 상담·다중 검색식 작성은 선택 경로로 유지하고 외부 AI 검색식은 기존 확인 후 실행 절차를 유지한다.
- 새 검색 성공 시 상위 최대 30편 자동 선택을 유지한다. 이후 필터·정렬·추가 수집은 현재 선택을 교체하거나 사용자가 해제한 논문을 다시 선택하지 않는다.
- 목록 밖에 선택된 논문 수를 표시하고 선택한 논문만 보기로 확인하게 한다. 전체 선택·해제 버튼은 현재 목록에 적용되며 그 범위를 문구로 명시한다.
- 원문 받기와 정리 프롬프트는 같은 정리 대상을 사용한다. 기본 화면의 기존 자동 선택 정책은 유지한다.

### 연구군·읽기 순서 작업

- 상단 주요 작업은 원문 받기 / 정리 프롬프트 복사 / 결과 가져오기다. 목록 위치와 무관하게 접근한다. 진행·취소·실패 상태를 표시한다.
- 본문은 자료 범위·선택적인 정리 초점·프롬프트 확인/수정·최신 정리본으로 구성한다. 이전 버전·편집은 별도 작업으로 전환하며 세로로 모두 쌓지 않는다.
- 조사 주제는 재사용하고 초점을 필수로 요구하지 않는다. 비어 있어도 연구군·읽기 순서 중심의 기존 지시서로 진행한다.
- 생성과 복사는 현재처럼 한 번 클릭으로 수행한다. 실패하면 직접 복사할 수 있게 한다. 대상 논문·전달 방식을 매번 다시 고르게 하지 않는다.
- summary-v3-gemini PDF 별도 첨부가 기본이며 본문 발췌 모드는 선택 설정으로 유지한다. 원문 부족은 표시하되 진행을 차단하지 않는다. 보관·첨부·독해·정확성 검증을 구분한다.
- 결과 가져오기는 .md 파일 또는 붙여넣기 중 하나로 진행한다. 기존 참조·내용 검사와 버전 보관을 재사용하고 오류 때 원문과 기존 결과를 보존한다. 이전 결과를 덮어쓰지 않는다.
- 정리본이 있으면 최신 결과를 기본 표시한다. 읽기 표시와 편집을 분리하고 Markdown 원문·[P#]를 보존한다. 안전한 기존 표시 방식을 재사용하며 HTML 실행을 허용하지 않는다. 사이트 내부 자동 군집화·새 AI 분석을 추가하지 않는다.

### 활용과 설정

- 활용 안에 논문 비교 / 발표문과 근거 / 목적별 외부 AI 도움 / 내보내기를 모으고 한 번에 하나만 표시한다.
- 비교 대상은 정리 대상과 독립적으로 명시 선택하는 2~4편이다. 기본은 미선택이며 정리 대상 30편을 자동 투입하지 않는다. 4편 초과 시 교체·해제를 안내하고 기존 대상을 임의 제거하지 않는다.
- 비교는 작업 공간 전체 폭을 사용한다. 돌아오면 이전 작업·목록 위치를 복원한다. 기존 비교값·근거를 지우지 않는다.
- PC 연결·수신함·연구실·검색식/검색 기록·이전 정리본 관리를 별도 설정/관리 화면으로 이동한다. 기존 기능을 모두 연결한다. 수신함 확인 요청·오류는 작업 헤더 알림에서 접근 가능하게 한다.

### 상태 보존

- 상세·작업·모바일 화면 전환과 다운로드 진행 갱신 때 메모·초점·수정 프롬프트·가져오기 입력·정리본 편집을 보존한다. 조사별 입력을 섞지 않는다.
- 입력을 상태에 반영한 후 화면을 전환하고 불필요한 전체 폼 재생성을 피한다. 비활성 작업의 대규모 DOM을 계속 만들지 않는다.
- 비교 대상·활성 작업·목록 위치는 정리 대상과 분리한 화면 상태로 관리한다. 저장 레코드와 안정적인 논문 번호를 변경하지 않는다.

## 완료 기준과 보고

- 기본 검색은 2회 → 1회, 상세는 제목 선택 1회, 프롬프트 생성·복사는 1회다. 필수 주제 재입력·대상 재선택이 없어야 한다.
- 필터·정렬 후 선택 유지, 비교/정리 대상 독립, 잘못된 결과 가져오기 후 이전 결과 보존을 검사한다.
- 1단계의 1440·1024·375px 구조와 주요 버튼 접근성을 유지한다. 기본 화면 회귀·checkJs·관련 단위/E2E 검사를 실행한다.
- 같은 시나리오의 변경 전후 클릭·필수 입력·스크롤을 구분해 보고한다. 기존 버전의 횟수를 측정하지 못했으면 미측정이라고 표시한다. 외부 Gemini 조작은 별도로 센다.
- 고정 자료 검증과 실제 검색·PDF·Gemini 검증을 구분한다. 실제 외부 작업을 자동 실행하지 않는다.

진행·결정·검증 문서를 실제 결과로 갱신하고 변경 파일·통합 기능·검사·화면 캡처·미비점을 보고한다. **2단계를 마치면 멈춘다.** 3단계 검증을 이유로 이번 변경의 기본 검사를 생략하지 않는다.
