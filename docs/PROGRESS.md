## 2026-10-14 8단계 서버·계정·클라우드 저장

Express가 정적 화면과 `/api`를 같은 출처로 제공한다. 허용한 HTML/CSS/JS만 열고 `.env`, 문서, 서버 코드는 열지 않는다.

**계정 설정이 없어 실제 Supabase 인증·DB는 호출하지 않았다. 고정 응답 테스트는 통과했고, 실제 인증/DB는 미검증이다.** 로그인 메뉴는 숨기고 예시 모드는 이 브라우저 저장을 유지한다. 로컬 예시를 클라우드로 자동 업로드하지 않는다.

- 검사: `tsc` 통과, Vitest 109개, Playwright 31개(번들 Chromium, 새 서버).
- 고정 응답으로 확인: 인증 누락, 만료 토큰, 로그아웃 후 차단, 다른 사용자 읽기/수정/삭제 차단, revision 충돌 시 미덮어쓰기, 삭제 실패 시 데이터 유지, 이메일 미확인과 비밀번호 오류 구분.
- 필요한 설정: `.env.example`의 `SUPABASE_URL`과 `SUPABASE_ANON_KEY`. 서버 전용 `SUPABASE_SERVICE_ROLE_KEY`는 사용자 요청에 쓰지 않는다. 마이그레이션은 `supabase/migrations/20261014_projects.sql`이며 원격에 적용하지 않았다.
- 실제 200% 확대, Supabase, OpenAI, Semantic Scholar, Crossref, PDF는 미검증.
- 다음 번호: **9**. 9단계는 실행하지 않았다. 커밋하지 않았다.

## 2026-10-14 재감사 결손 5건 수정

독립 재감사(64/70, P0 보류)에서 재현된 항목을 고쳤다. **P0 완료로 다시 채점하지 않았고 8단계는 시작하지 않았다.**

- 저장: 다른 조사를 열거나 첫 화면·새 검색으로 나가기 전에 대기 중인 저장을 끝낸다. 저장이 실패하면 화면을 바꾸지 않는다. 현재 조사를 삭제할 때만 대기 저장을 버린다.
- 손상: `null` 근거·위치는 예외 없이 복구 화면으로 가고, 그 항목이 저장 목록 전체를 막지 않는다. 적용 조건이 없으면 빈 문자열로 연다.
- 이전: 구버전 비교 셀 `{value, history:[{value}]}`를 `{cell, history:[{cell}]}`로 바꾼다. 원본 객체는 그대로 둔다.
- 참조: 없는 근거 ID, 근거와 논문 불일치, 방향의 다음·대표·최근 논문 ID는 거부한다.
- 발표 가이드: 요약과 같이 메모·수정 수치·단위·측정 조건을 넣는다.
- 검사: `tsc` 통과, Vitest 102개, Playwright 31개(번들 Chromium). 실제 200% 확대와 외부 연동은 미검증.

## 알려진 한계·남은 문제
- `src/app.js`가 한 파일에 크고 타입 검사에서 제외됨. 이후 단계에서 분리 필요.
- 연구 방향 추천·논문 분류·비교 값은 모두 직접 작성한 가상 예시. 수치는 만들지 않았고 결과/조건 셀은 "원문 미확보".

- 연구실의 "기존 논문" 입력은 저장만 하고 분석에 쓰지 않음(DOI 조회는 9단계).
- 분석 버전(`versions`)은 범위 변경마다 기록하지만 비교 UI는 없음(11단계).
- 방향 비교와 논문 비교 표는 모바일에서 카드 전환 대신 표 영역 안 가로 스크롤을 사용.
- 헤더에서 "저장한 조사"는 페이지 내 목록으로 이동. 로그인 메뉴는 숨김.
- 이 브라우저(IndexedDB)에 저장된다는 점만 표시. 계정 보안이 아님.
