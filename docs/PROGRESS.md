- 선택 권한은 현재 탭에서만 유지한다. 브라우저 미지원·권한 거부·저장 실패 시 직접 폴더 저장은 보장되지 않는다. 폴더 확인은 자동 감시가 아닌 버튼 실행이다.
- checkJs, 전체 Vitest 210개, workspace Chrome E2E 9개 통과. 파일 시스템 모의 객체와 가상 PDF를 이용해 저장·이름 변경 후 DOI 연결을 확인했다. 실제 PC 폴더 선택·권한·저장과 공개 사이트 배포는 미검증이다.

- checkJs, 관련 Vitest 15개 통과. Chrome E2E에서 가상 PDF의 다운로드 이벤트·파일명·오류 없음을 확인했다. 다른 PC의 실제 기본 다운로드 폴더와 공개 사이트 배포는 이번에 확인하지 않았다.

## 알려진 한계·남은 문제
- `src/app.js`가 한 파일에 크고 타입 검사에서 제외됨. 이후 단계에서 분리 필요.
- 연구 방향 추천·논문 분류·비교 값은 모두 직접 작성한 가상 예시. 수치는 만들지 않았고 결과/조건 셀은 "원문 미확보".
- 연도·인용수 일부는 정렬 시연용 가상 값(화면에 "가상 값" 표기).
- 연구실의 "기존 논문" 입력은 저장만 하고 분석에 쓰지 않음(DOI 조회는 9단계).
- 분석 버전(`versions`)은 범위 변경마다 기록하지만 비교 UI는 없음(11단계).
- 방향 비교와 논문 비교 표는 모바일에서 카드 전환 대신 표 영역 안 가로 스크롤을 사용.
- 헤더에서 "저장한 조사"는 페이지 내 목록으로 이동. 로그인 메뉴는 숨김.
- 이 브라우저(IndexedDB)에 저장된다는 점만 표시. 계정 보안이 아님.
