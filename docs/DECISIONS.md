# 결정 기록

## 2026-10-23 Gemini 첨부 중심 정리 지시서

- 기본 summary-v3-gemini는 지침과 [P#]·제목·DOI·파일명만 전달한다. 본문·초록·전체 서지정보를 반복하지 않는다. PDF와 이전 정리본은 사용자가 Gemini에 별도 첨부한다.
- 첨부 완료 후 정리 시작을 요청하며, Gemini가 읽을 수 있는 파일과 논문 목록을 대조하도록 한다. 보관 상태를 실제 첨부·독해 완료로 간주하지 않는다.
- 기존 본문 발췌 방식은 선택 옵션으로 유지한다. 연구군·읽기 순서와 [P#] 추적을 유지하며 응답의 전체 DOI·서지목록 반복을 생략한다.

## 2026-10-23 로컬 PDF 수신함

- 로봇 확인은 사용자가 브라우저에서 직접 처리한다. 서버는 확인을 풀거나 쿠키를 받지 않는다.
- 직접 넣은 PDF와 서버가 받은 PDF 모두 data/inbox-pdfs에 둔다. 자동 가져오기 감시는 기본으로 꺼져 있고, 현재 조사에 연결을 누른 조사에만 연결한다. 예전 data/pdfs 출력은 더 이상 쓰지 않는다.
- 문서 DOI가 그 조사의 논문 한 편과 맞을 때만 자동 연결한다. 애매하면 사용자가 고른다. 브라우저 저장이 끝난 뒤에만 처리 완료로 기록한다.

## 2026-10-23 탐색 목록 30편과 원문 일괄 받기

- 실검색 화면은 거르기 결과의 상위 30편만 보여 주고, 그 30편을 선택으로 맞춘다. 예시는 기존처럼 5편씩 펼친다.
- 원문 일괄 받기는 공개 원문을 먼저 시도하고, 실패한 DOI만 Sci-Hub로 순서대로 받는다. 같은 버튼으로 취소한다. 로봇 확인이 나오면 남은 Sci-Hub 시도는 멈추고 표시만 한다.
- 브라우저 PDF 보관 한도는 조사당 30개·600MB, 파일당 20MB다. 서버의 별도 파일 정책(5개·100MB)은 바꾸지 않았다.

## 2026-10-23 새로고침은 저장본을 열지 않음

- 페이지를 새로 열거나 새로고침하면 작업 화면을 비운다. 주소의 조사 번호도 저장본을 자동으로 열지 않는다.
- 조사 내용은 IndexedDB에 남긴다. 저장한 조사 목록의 열기, 상태 보기로만 불러온다.
- 같은 탭에서 뒤로 가기와 앞으로 가기는 주소의 조사를 그대로 연다.

## 2026-10-22 내 ChatGPT는 복사로 연결

- 개인 ChatGPT는 사용자가 대화에 붙여 넣는 외부 AI다. 사이트는 API 키, 로그인, 브라우저 자동 전송을 쓰지 않는다.
- 상담·관련성·읽기·방향·비교·랩미팅·검색 보완·피드백·연구군 정리는 목적별 프롬프트를 만들고, 구조화된 답변만 확인 후 적용한다. 읽기·랩미팅 글은 메모로 보관한다.
- 삭제했던 예시 연구 방향 카드는 되돌리지 않는다. ChatGPT 방향 초안은 별도 목록이다.
- 검색 문구와 피드백을 적용해도 논문 재검색과 평가 자동 갱신은 하지 않는다.

## 2026-10-22 연구군·읽기 순서 기본 지침

- 선택 논문의 기본 분석을 `summary-v2` 연구군·읽기 순서로 변경한다. 문제·접근법별 분류 근거, 첫 논문과 이유, 공통 입문 및 관심사별 학습 경로를 요청한다.
- 자료 수에 맞게 분류·추천하고 중복 소속·미분류·추천 보류를 허용한다. 검색 정렬과 학습 순서, 선택 논문 집합과 분야 전체를 구분한다.
- 실제 전달 텍스트를 기준으로 메타데이터만/초록만/원문 일부를 집계한다. 이전 정리본도 현재 자료로 재확인하며 독립 근거로 취급하지 않는다.
- 외부 AI 수동 복사·가져오기 구조와 기존 저장본을 유지한다. 입력 묶음 파일 내보내기·사이트 내부 자동 군집화는 이번 범위에 넣지 않는다.

## 2026-10-22 Sci-Hub 다운로드 구현

- 사용자의 구현·검증 요청에 따라 검증된 직접 HTTP 어댑터를 사용한다. 검색 공급자는 OpenAlex·Crossref를 유지하고 Sci-Hub는 논문 카드의 명시적 DOI 원문 요청만 처리한다.
- MCP 서버를 설치하거나 모델 API를 호출하지 않는다. 기존 MCP 요구 중 원문 확보 목적을 직접 연결로 구현했으며 MCP 연동 완료로 표현하지 않는다.
- PDF 원본과 페이지별 텍스트를 IndexedDB에 보관하고 원본 저장 버튼을 제공한다. 조사당 5개·100MB, 파일당 20MB를 적용한다. 원본 포함 전체 백업·서버 파일 저장은 미구현이다.
- 실제 Sci-Hub 다운로드 검증은 사용자가 지정한 한 편 범위로 제한한다. 검색은 고정 서지정보를 사용하며 실검색 성공으로 집계하지 않는다.

## 2026-10-21 유료 AI 없는 핵심 흐름 (이전 AI 호출 결정보다 우선)

- 상담 출력 보완: 사용자 선택·확정 기준 대기를 없애고 첫 응답에 잠정 주제와 검색식 5~8개를 요청한다. 질문·가정을 보존하고 실행 전에 표시한다. 빈 주제·core·검색식 및 비영문·연산자·중복 검색식은 원문과 이전 결과를 포함한 보완 요청으로 복구한다. 기존 1~4개 검색식은 경고 후 허용한다.

- 핵심 흐름은 개인 AI 상담 결과를 붙여 넣거나 검색식을 직접 작성한 뒤, 다중 검색·중복 제거·규칙 정렬(`rule-v1`)·저장으로 이어간다. 사이트는 OpenAI를 호출하지 않는다.
- 키가 `.env`에 있어도 서버는 OpenAI 클라이언트를 만들지 않는다. 해석·검색식 생성 라우트는 호출을 거절한다. 기존 AI 모듈과 개인 `.env`는 삭제하지 않았다. 단가 기록은 역사적 코드로 남긴다.
- 규칙 정렬 가중치: 핵심 단어 제목 4점(상한 12), 초록 2점(상한 8), 동의어 묶음은 제목 2·초록 1로 한 번, 선호 단어 1점(상한 4), 서로 다른 검색식 1점(상한 3). 최신성·인용 수는 이 점수에 넣지 않는다. 같은 점수는 ID 오름차순이다.
- 제외 단어가 제목이나 초록에 있으면 제외 이유와 함께 목록 뒤에 두고, 사용자가 해제할 수 있다. 초록이 없으면 정보 부족으로 표시하고 무관으로 확정하지 않는다.
- Sci-Hub MCP 다운로드는 이번에도 구현하지 않았다. 공개 주소만 보여 준다.

## 2026-10-21 교수님 말씀 조사 흐름

- 검색이 켜져 있으면 주 버튼은 바로 검색하지 않고, 전송 동의 뒤에만 gpt-5.4-mini로 말씀을 정리한다. 동의하지 않으면 현재 문장으로 넓게 탐색할 수 있다.
- 범위가 넓으면 세부 주제를 강제하지 않는다. 상담 프롬프트 복사와 상담 결과 붙여넣기는 선택이며, 확인한 내용만 기준에 넣고 원래 발언은 유지한다.
- 검색식은 사용자가 수정·제외한 뒤 최대 8개, 한 번에 2개씩 실행한다. DOI 또는 공급자 ID로만 합친다. 전부 실패하면 예시 논문으로 바꾸지 않는다.
- 관련성 평가는 조사 질문과의 맞음만 본다. 반환 ID가 수집 결과에 없거나 평가가 실패하면 검색 결과를 유지하고 “관련성 평가 미완료”로 남긴다.
- Sci-Hub MCP로 원문을 받지 않는다. 공개 주소는 링크만 보여 주고 다운로드·추출·분석으로 세지 않는다.

## 2026-10-21 검색 변경 (이전 검색 결정에 우선)

- OpenAlex 주 검색 + Crossref 이메일 기반 결측 보완/장애 시 공개 검색. Semantic Scholar 키는 사용하지 않는다.
- `OPENALEX_API_KEY`는 선택이며 OpenAlex Authorization에만 전달한다. `CROSSREF_MAILTO`는 실제 본인 연락 이메일이다. 이메일이 없으면 개별 보완은 생략하되 Crossref 장애 대체 검색은 가능하다.
- 공개 검색을 기본 켜며 오프라인·예시 검사는 `SEARCH_ENABLED=false`로 실행한다. 키 없는 호출량은 제한되며 무제한 무료라고 설명하지 않는다.
- 실제 자료도 real 모드를 유지하며 브라우저에 보존한다. 계정 보안과 다르며 예시 혼합은 차단한다.
- PDF/XML 후보 링크와 본문 확보·추출·분석을 분리한다. 이번에는 자동 원문 분석을 추가하지 않는다. 실제 문헌에 예시 비교값·방향을 생성하지 않는다.
- 개인 `.env`는 자동 수정하지 않는다. 브라우저 회귀는 작성했으나 실행 승인 거절로 미검증이다.

## 3~7단계 추가 결정
- 개발 서버는 임시 scripts/serve.js(허용 경로만 제공). 8단계에서 Express로 교체.
- src/app.js는 @ts-nocheck. DOM 이벤트 타입 잡음 때문이며 로직은 logic.js로 분리해 검사한다. tsconfig는 strict:false.
- 기존 script.js는 삭제하고 새 모듈로 교체(Git 기준 커밋에 남음).
- 방향 분류·비교 값은 직접 작성한 가상 예시이며, 결과·조건 셀은 의도적으로 '원문 미확보'로 둠.
- 전체 UI를 한 페이지의 랜딩 + 작업 공간(탭 2개)으로 구성. 요금 섹션은 FAQ로 통합.
- URL에는 topic 키와 탭만 넣고 입력 원문과 연구실 정보는 넣지 않음.
- 테스트용 훅 window.__rl.failNextSave로 저장 실패를 재현(실제 사용 기능 아님).


## P0 결손 보완 결정
- 주소는 `?project=<무작위 ID>&tab=`만 사용. 입력 원문은 넣지 않는다. `?topic=`은 새 조사 시작용이며 곧 치환한다.
- 저장 레코드는 `papers` 스냅샷과 `exampleDataVersion`을 가지며 스키마 v2. v0/v1은 예시 논문으로 복원 이전한다. 더 새로운 버전은 읽기 전용.
- ID 접두사: `user:`는 모든 모드, `example:`/`fx:`는 실모드에서 거부.
- 사용자 직접 추가 논문은 `user:` ID·origin user, DOI는 형식만 검사(조회 안 함).
- 손상 데이터는 자동 삭제·덮어쓰기를 하지 않는다. 손상·읽기 전용 상태는 저장하지 않는다.
- `app.js` 분리로 `@ts-nocheck`를 제거하고 `strictNullChecks`를 켰다(`strict`는 여전히 false).
- 최초 상호작용(커밋 `ae9f22b`의 `script.js`)은 가상 예시 3종(리그닌·전고체·페로브스카이트)과 탭 전환 정도였으며 새 구현으로 대체됐다.

## 10~14단계
- 모델 단가를 확인하지 못하면 OpenAI를 호출하지 않고, 지정 모델 실패를 다른 모델로 바꾸지 않는다.
- 동의는 프로젝트·목적·자료 범위·문구 버전에 묶는다. 철회는 이후 전송만 멈추며 공급자 저장분 삭제를 주장하지 않는다.
- PDF 원문은 사용자가 가져오거나 올릴 때만 다룬다. 공개 PDF 주소만으로 재사용 권한을 확정하지 않는다.
- 작업 큐와 30일 파일 정리는 `npm start` 프로세스 안에서 1분 간격으로 돈다.

## 9단계
- 아래 검색 키 조건은 2026-10-21 OpenAlex 전환으로 대체됐다. 현재 기준은 위 “2026-10-21 검색 변경”이다.
- 한국어는 확인된 반도체 용어만 영문으로 바꾼다. 사전에 없는 말은 사용자가 영문 검색어를 직접 고친다.
- 한국어는 확인된 반도체 용어만 영문으로 바꾼다. 사전에 없는 말은 사용자가 영문 검색어를 직접 고친다.
- 공개 검색은 1시간, 0건은 5분, 논문 메타데이터는 24시간 캐시한다. 개인 검색은 사용자별로 나누고, 로그인하지 않은 개인 검색은 공유 캐시에 넣지 않는다.
- 원문 주소는 링크만 보여 주고 다운로드하지 않는다. 추천 이유는 규칙 기반이며 AI가 아니다.

## 8단계
- 계정이 없으면 로그인 메뉴를 숨기고 예시 모드(브라우저 저장)만 연다. 인증이 필요한 API는 예시 데이터로 대체하지 않고 거절한다.
- 프로젝트 소유자는 요청 본문의 userId가 아니라 검증된 토큰의 사용자다. service-role 키는 일반 요청의 인증으로 받지 않는다.
- 다른 탭의 저장은 revision이 다르면 409로 거절한다. 사용자가 서버 revision을 확인한 뒤에만 다시 저장한다.
- 클라우드로 옮기는 조사는 사용자가 “가져오기”를 누른 프로젝트뿐이다.
- 연구실 정보의 클라우드 위치는 프로젝트 기록의 `lab` 필드다. 외부 AI 전송 동의는 10단계이며 이번 저장과 별개다.

## 재감사 후속
- 조사를 바꾸기 전에 대기 중인 자동 저장을 끝낸다. 저장 실패 상태에서는 이동하지 않아 화면의 변경을 버리지 않는다.
- 구버전 셀은 읽을 때 새 형식으로 바꾼다. 값이 비어 있고 사유가 없으면 `not_found_in_sources`로 두어 빈칸을 추정 값으로 채우지 않는다.
- AnalysisProvider 계약은 `analyze({topicKey, papers, scope, userMeta})`가 방향 결과를 반환하는 현재 구현과 맞춘다.

## 세부 검색·총정리
- 제외 단어는 OpenAlex 문법에 넣지 않고 화면에서만 적용한다(지원하지 않는 연산자를 만들지 않음). 숨긴 논문은 지우지 않고 해제할 수 있다.
- 자동 키워드는 제목·초록의 단어·두 단어 표현 빈도다. 의미 판단이 아님을 표시한다.
- 원문은 OpenAlex 공개 위치, Unpaywall 공개 사본, 사용자가 올린 PDF만 쓴다. Sci-Hub 등 비공개 경로는 쓰지 않는다. 서버는 https·사설 IP·리다이렉트·20MB·20초·%PDF를 검사하고 PDF 바이트를 저장하지 않는다. 도서관 프록시는 링크만 열고 계정 정보를 받지 않는다.
- 총정리 프롬프트는 논문마다 [P#] 번호와 자료 범위(초록만/원문 추출)를 적고, 원문 발췌는 논문당 12,000자까지로 자른 사실을 표시한다. 돌아온 md는 형식만 검사하고 '정확성 미검증'으로 보존한다.
- 용어: 사용자 화면의 '검색식'을 '검색 문구'로 바꿨다.
