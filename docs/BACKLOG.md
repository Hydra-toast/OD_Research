# 백로그

## 기본 작업 화면 통합 후 검증

- 구 화면 탭/예시 버튼에 의존하는 기존 E2E를 기본 작업 화면으로 이관한다. 신규 workspace E2E 5개와 단위 검사 206개는 통과했으나 기존 전체 E2E 통과를 의미하지 않는다.
- 실제 검색·PDF 수신·외부 AI 수동 왕복과 배포 사이트는 별도 검증한다.

## 이번 범위 제외 (재검토하지 않음)
연구 공백 자동 발견, 교수 의도 확정, 과제 수주·랩미팅 통과 보장, 자신감·준비도·적합도 점수, 일정 관리(7일·14일 계획), 자동 PPT 디자인·제작, 가격·결제·유료 잠금, 공개 판매·구독.

## 후속 기능과 재검토 조건

개인용 현재 요구와 우선순위는 `.cursor/Research-Landscape-PRD.md` v2.3을 따른다.

### 개인용 우선 보완

- 목적별 외부 AI 프롬프트: 2026-10-22에 ChatGPT 복사 패널로 관련성·읽기·방향·비교·랩미팅·검색 보완·피드백을 넣었다. 연구군·읽기 순서는 기존 섹션이다. 묶음 파일 분할, 비교 수치의 확인된 셀 반영, 방향 카드 UI 재연결, 실제 ChatGPT 품질 확인은 후속이다.
- 응답 누락·오래된 기준·일반 문장·과대 입력 복구.
- 검색식 편집·부분 실패·규칙 정렬·출처 보존과 수동 경로 확인.
- 전체 조사 백업·복원, 파일 포함 범위와 저장 충돌 처리.
- Sci-Hub 직접 HTTP 수집·브라우저 PDF/본문 보관은 2026-10-22 구현. 받은 PDF 파일과 수동 PDF는 data/inbox-pdfs에 둔다. 원본 포함 전체 백업과 MCP 프로세스 연동은 후속이다.

### 별도 요청 전 보류

클라우드 동기화·계정 서비스·공개 배포·모델 API 연결·OCR. 기존 관련 코드를 임의 삭제하지 않는다.

| 기능 | 재검토 조건 |
|---|---|
| 복잡한 citation graph | 카드·목록보다 판단에 도움이 된다는 사용자 근거 확보 |
| 여러 분야 자동 공정 추출 | 개인 수동/외부 AI 비교 유용성 확인 후 별도 요청과 분야별 검증 |
| 연구자·기관 분석 | 핵심 흐름 검증 후 수요 확인 |
| 새 논문 알림 | 반복 사용 근거 확보 |
| 장기 동향 추적 | 집계 범위·수집 시점을 표시할 수 있는 시계열 확보 |
| 분야별 전문 템플릿 | 일반 검색·정리는 전공 제한 없이 지원, 전문 항목은 개인 사용 요구에 맞춰 추가 |

- 총정리 후속: 스캔 PDF OCR, md의 Mermaid 화면 렌더링, 선택 논문이 많을 때 묶음 분할 프롬프트, 실제 OA PDF·Unpaywall 사용 검증.
