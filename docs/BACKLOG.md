| 기능 | 재검토 조건 |
|---|---|
| 복잡한 citation graph | 카드·목록보다 판단에 도움이 된다는 사용자 근거 확보 |
| 여러 분야 자동 공정 추출 | EUV PR 한 주제에서 추출 정확성 검증 완료 |
| 연구자·기관 분석 | 핵심 흐름 검증 후 수요 확인 |
| 새 논문 알림 | 반복 사용 근거 확보 |
| 장기 동향 추적 | 집계 범위·수집 시점을 표시할 수 있는 시계열 확보 |
| 결제·구독 | 무료 탐색 이용 후 근거 정리 수요 검증, 가격·사용량 검증 |
